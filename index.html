Flagship project

SEC Holdings Lakehouse

Every quarter, US investment managers with more than $100M under management file Form 13F with the SEC. The data is public but messy: amendments restate earlier filings, value units changed in 2023, and the same manager or security shows up under many names. I am building a lakehouse that makes it queryable and trustworthy, end to end, on my own hardware.

Medallion lakehouse on Dagster, PySpark and Delta Lake

One Docker image runs every role (Dagster webserver and daemon, Spark master and workers), so versions match across dev and staging. Code reaches the homelab UAT environment only through CI, and each milestone starts with a spec and architecture decision records.
